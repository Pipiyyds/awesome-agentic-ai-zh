# 版本与后续管理

原来源：https://github.com/WenyuChiou/awesome-agentic-ai-zh；下载基线：83775cf3cdef26717a4e40d8928de57ae869b8d7；核对日期：2026-10-08。

1. 每次正式继续学习先读取 PROGRESS.md 和 tasks.json，再读当前原章。用户修改与实际证据优先。
2. 每节登记输入、输出、时间、错误、变式和产物。done 只表示该任务验收完成，技能掌握仍要求独立迁移。
3. 每周在学习对话中核对原仓库是否有影响当前节点的变化，先看 diff，再决定更新；不自动覆盖个人日志或追新版本。
4. 上游原文件与个人规划分开。完整下载不含 Git 历史；SOURCE_MANIFEST.json 记录每个原文件的 Git blob SHA 与 SHA-256。
5. 对原资料作版本更新时重新记录 commit、差异和受影响任务；一个正在做的练习固定版本，除非已发现需要修复的问题。
6. 新资料必须写清对应节点、解决的卡点、来源、核查范围和优先级；资料库不能替代实作。
7. GitHub 写入后读取远程入口、任务表和 PDF 元数据验证，记录 commit。没有成功返回与远程证据不能宣布已保存。
8. 任何持续后台提醒、自动周报或账户接入需另行设定明确范围、频率、数据源和实际可用权限；本次未创建这些自动化。
